# Seedance Director

Muse-adapted director skill, based on Emily2040/seedance-2.0 (MIT, Seedance 2.0 Skill OS, repo SKILL.md v6.7.0, https://github.com/Emily2040/seedance-2.0).
Muse does not run the repo's 28 sub-skills natively, so this file is the Muse version: the directing loop, not a copy of the whole pack. For the full sub-skills, references and evals, read that repo.

Scope warning, from the source skill itself: this is for Seedance 2.0 only. A newer model line (for example 2.5) is out of scope for its numbers: duration, reference ceiling, resolution and model IDs from 2.0 must never be restated for another line. The craft still applies (direction, shot contracts, reference roles, continuity, anti-slop); the numbers do not. When the model line is unknown, write the prompt and withhold the number.

Use when 帅东 wants a Seedance video clip, a sequence, or a prompt for one, including for the AI short drama 《拾愿者》 in rest time.

Core loop:
1. Intake: goal, phase, surface (Dreamina / Jimeng / CapCut / Doubao / Volcengine / Ark / BytePlus / fal / third-party router), mode (T2V / I2V / V2V / first-last-frame), duration, aspect ratio, references, audio / dialogue / lip-sync needs, deliverables, safety and IP risks. Never claim to have viewed, watched or heard a reference that Muse cannot inspect; mark user-reported details as user-reported.
2. Director's Read first: before drafting a prompt, compress the idea into intent, dramatic function, want, obstacle, turn, suppressed behaviour, one non-transferable detail, and the stock solution refused. Translate that into visible carriers only: blocking, eyeline, gesture, prop use, spatial change, camera endpoint, motivated light, dialogue contradiction, silence, sound cue. Do not hand translation work back to the user.
3. Fast lane for a single standalone clip with no IP / likeness / brand / safety flag: one visible beat, one motivated camera move, one motivated light source, sound intent, directing coherence. Keep the single-clip prompt compact (about 40-110 words for 2.0) and keep director language in the internal brief, plain words to the user.
4. Sequence work: classify standalone_clip vs sequence_project first. Hold story state across clips: subject, mode, look, references, decided constraints, what failed before. A new request inherits the world already built; do not make the user repeat a decision.
5. Safety / IP gate: if IP, likeness, brand, real person or evasion risk appears, stop and go to safety before planning. Use IP-safe rewrites where needed. Prompt writing does not authorise a paid generation, account login, or external upload; before any generation, confirm provider, assets, action and spending limit with the user.
6. For 《拾愿者》: keep its frozen rules — locked world rules, cost of rewriting reality, armour upgrade lines, and the theme of "记得" — and keep character / armour reference images consistent across clips. Do not change a key line or rule to fit a prompt.

Do not use this skill for non-Seedance models (Sora, Veo, Kling, Runway's own Gen models) or image-only prompting, and do not present 2.0 platform numbers as 2.5 numbers.
